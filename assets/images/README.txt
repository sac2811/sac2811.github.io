DEVCRAFT PORTFOLIO IMAGE GUIDE


hero/

Contains:
- Hero section backgrounds
- Developer workspace images
- Coding environment images


profile/

Contains:
- Professional developer profile photo


portfolio/

Contains:
- Website screenshots
- Application previews
- Project thumbnails


icons/

Contains:
- Technology logos
- Framework icons


clients/

Contains:
- Client testimonials images



IMAGE REQUIREMENTS


Use WebP format whenever possible.


Avoid:
- Large PNG files
- Uncompressed screenshots
- Random filenames


Recommended tools:

- TinyPNG
- Squoosh
- Photoshop Web Export
